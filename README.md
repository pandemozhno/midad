## 0. Три железных правила

1. **Табы, не пробелы.** Один уровень = один таб. Смешение — ошибка.
2. **Символ — это символ, слово — это слово.** `+`, `==`, `&` — нотация, не сокращения, остаются как есть. `and`, `or`, `not`, `function`, `as` — полные слова, **переводятся на любой из четырёх языков** через `.sema`. См. раздел 2.
3. **Один `.mid` — один `module`.** Файл начинается с профиля (`@kernel`, `@flow`, `@view`, `@light`), затем `module имя`.

## 1. Профили

Профиль — это набор правил компилятора. Пишется первой строкой файла, отдельным токеном `@имя`.

| Профиль | Что разрешено | Что запрещено | Бэкенды |
|---------|---------------|---------------|---------|
| `@kernel` | `assembly`, `unsafe`, `static mutable`, `external C`, `no standard`, `entry` | `show`, `rule` | C, native |
| `@flow` | `show`, `rule when … then`, `emit`, структуры, протоколы | `assembly`, `unsafe` | C, JS, WASM, native |
| `@view` | `show`, виджеты | `assembly`, `unsafe` | C, JS, WASM |
| `@light` | шейдеры, векторы, `float32`/`float64` | `assembly`, `unsafe`, `show` | SPIR-V, WGSL |

Проверка профиля — на этапе `checker`. Нарушение — ошибка компиляции, не runtime.

## 2. Многоязычный код

**Ключевая идея Midād: один и тот же код можно писать на любом из четырёх человеческих языков.** `en`, `ru`, `ar`, `zh` — равноправны. Компилятор переводит поверхность в канонический SEM и только потом генерирует код.

### 2.1. Что переводится

| Что | Пример en | Пример ru | Пример ar | Пример zh |
|-----|-----------|-----------|-----------|-----------|
| **Ключевые слова** | `function` | `функция` | `دالة` | `函数` |
| **Типы** | `integer32` | `целое32` | `صحيح32` | `整数32` |
| **Имена из `[names]`** | `main` | `главная` | `الرئيسية` | `主` |
| **Логические операторы** | `and` / `or` / `not` | `и` / `или` / `не` | `و` / `أو` / `ليس` | `和` / `或` / `非` |

Локализация — через файлы `sema/{en,ru,ar,zh}.sema`. Один канонический ID → одно локализованное слово.

### 2.2. Что **не** переводится

| Что | Почему |
|-----|--------|
| **Символы** `+`, `==`, `&`, `<<` | Математическая нотация, не слова |
| **Строковые литералы** `"Hello"` | Это данные, не код. `show "Привет" as text` — приветствие, но код — на английском |
| **Комментарии** `-- …` | Текст для человека, компилятор не трогает |
| **`@kernel`, `@flow`, `@view`, `@light`** | Имена профилей — системные, всегда английские |
